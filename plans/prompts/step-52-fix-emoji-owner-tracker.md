# step-52-fix-emoji-owner-tracker.md

## Контекст

В [`src/owner_tracker.py`](src/owner_tracker.py) в KPI-отчёте при отправке в чат Bitrix24 возникает проблема с эмодзи.

Строка 168:
```python
plan_text = f" ({pct}% плана, осталось {rem})"
```

Когда `rem` = 8, получается `осталось 8)`. В чате Bitrix24 последовательность `8)` парсится как смайлик 😎, искажая текст.

Та же потенциальная проблема на строке 164:
```python
plan_text = f" ✅ (+{diff} сверх плана)" if diff > 0 else " ✅"
```
Здесь `плана)` — закрывающая скобка после слова, но при определённых комбинациях тоже может сработать.

## Задача

Исправить форматные строки так, чтобы `N)` не образовывалось.

---

## Шаг 1 — Исправить строку 168

### Где

Файл: `src/owner_tracker.py`, функция `format_kpi_report`, строка 168.

### Текущий код

```python
plan_text = f" ({pct}% плана, осталось {rem})"
```

### Новый код

```python
plan_text = f" ({pct}% плана, осталось: {rem})"
```

**Почему:** двоеточие после «осталось» разрывает паттерн `N)` → `8)` больше не образуется.

---

## Шаг 2 — Исправить строку 164 (профилактика)

### Где

Файл: `src/owner_tracker.py`, функция `format_kpi_report`, строка 164.

### Текущий код

```python
plan_text = f" ✅ (+{diff} сверх плана)" if diff > 0 else " ✅"
```

### Новый код

```python
plan_text = f" ✅ (+{diff} сверх плана)" if diff > 0 else " ✅ (план выполнен)"
```

Или оставить как есть — здесь `плана)` а не `N)`, так что проблема маловероятна. Но для единообразия лучше добавить текст после скобки или убрать скобку.

---

## Проверка

1. Запустить `python src/owner_tracker.py` с `DRY_RUN=true`
2. Убедиться, что в выводе нет паттернов вида `осталось 8)` (должно быть `осталось: 8)`)
3. Отправить тестовое сообщение в чат — эмодзи не должны появляться
