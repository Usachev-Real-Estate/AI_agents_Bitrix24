## Задача 4: UTF-8 очистка в коллекторах (`src/tools.py`)

В функциях `get_all_leads_with_timeline` и `get_deals_by_funnel_with_timeline`, после извлечения текстовых полей, добавить очистку:

```python
def _clean_str(value: Any) -> str:
    """Clean string from encoding artifacts."""
    s = str(value) if value is not None else ""
    return s.encode("utf-8", errors="replace").decode("utf-8")
```

И заменить все `str(deal.get("TITLE") or "")` на `_clean_str(deal.get("TITLE"))` в обеих функциях.
