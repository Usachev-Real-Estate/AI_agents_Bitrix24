# 20. Чтение комментариев брокеров моделью: ежедневно в 04:05 МСК (01:05 UTC).
#     Стоит между ночными инкрементами и полной сверкой витрины (05:35 МСК):
#     комментарии прошедшего рабочего дня к этому часу уже залиты, а утренний
#     дайджест (09:00 МСК) читает то, что разобрано этой ночью.
#
#     :05, а не :00 — потому что в :00 тикает инкремент, и 21.09 они
#     столкнулись минута в минуту. Читатель упёрся в его транзакцию первой
#     же карточкой, подождал свои десять секунд и умер; в базу не попало
#     ничего, а пул успел дочитать ещё четыреста оплаченных ответов в
#     мёртвый процесс. Пять минут дают ему стартовать на свободной витрине.
#
#     Полностью развести их сеткой нельзя: прогон идёт около четверти
#     часа и всё равно накроет следующий тик. Поэтому сетка — только
#     половина дела; вторая половина в коде: ETL отпускает запись перед
#     КАЖДЫМ обращением к порталу (коммитов между этапами оказалось мало —
#     самый долгий этап держал замок 81 секунду внутри себя), а читатель
#     повторяет свою запись с отступом. Замер 22.09: обе задачи шли бок о
#     бок 76 секунд, читатель не ждал ни разу.
#
#     До 21.09 задача стояла в 06:00 МСК, и здесь значилось, что сверка идёт
#     в 03:30 — ошибка пересчёта UTC в МСК на два часа.
#
#     Ночью читается только изменившееся — карточки, где брокер что-то
#     дописал. Сколько их набегает за сутки, честно сказать пока нельзя:
#     замер в разгар рабочего дня дал 72 карточки за два часа, а замер
#     21–22.09 — 46 за шестнадцать часов, из которых семь рабочих. Разница
#     впятеро, и она не объяснена: то ли день на день не приходится, то ли
#     первый замер пришёлся на пик. Лимит выбран по большему числу.
#
#     Настоящая цифра станет видна в первую же ночь, когда очередь уйдёт в
#     ноль: наутро в ней окажется ровно суточный приток, и вот его сюда и
#     надо будет записать.
#
#     Лимит 400 — потолок, а не норма. Замеры на живом портале 22.09, два
#     прогона на 460 карточек: 1,6–2,0 секунды и 0,35–0,46 ₽ на карточку.
#     Разброс цены идёт от доли размышлений в ответе — 79% выходных токенов
#     в одном прогоне против 88% в другом; за это и платится.
#
#     Значит худшая ночь при этом лимите стоит около 180 ₽ и четверть часа,
#     а до дайджеста остаётся больше двух часов. (До 22.09 здесь стояли
#     3 секунды на карточку и двадцать минут — прикидка сверху, сделанная
#     до первого замера. Она не мешала, но и не годится: по ней нельзя
#     понять, ухудшилось ли что-то.)
#
#     Меньше брать нельзя: потолок, в который упираются каждую ночь, — это
#     не предохранитель, а узкое место, и выглядит оно как успешный прогон,
#     пока разбор отстаёт на день, потом на два. Остаток очереди пишется в
#     лог отдельной строкой — по ней и видно, мал ли лимит.
#
#     Смена версии промпта отправляет на перечтение ВЕСЬ портфель: 1050
#     карточек — это 35 минут и ~480 ₽ по тем же замерам. Такой прогон
#     делается руками сразу после правки, а не размазывается на неделю
#     ночных лимитов:
#       docker run --rm --env-file .env -v $(pwd)/logs:/app/logs \
#         -v $(pwd)/data:/app/data b24-ai-auditor:latest \
#         python src/comment_reader.py --limit 1200
5 1 * * * cd /home/Ai_agents_crm && scripts/cron_job.sh comment-reader docker run --rm --env-file .env -v $(pwd)/logs:/app/logs -v $(pwd)/data:/app/data b24-ai-auditor:latest python src/comment_reader.py --limit 400 >> logs/cron.log 2>&1
