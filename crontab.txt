# b24-ai-auditor: расписание отчётов
#
# Каждая задача запускается через scripts/cron_job.sh:
#   * flock — запуск не накладывается на предыдущий (важно для chat-poller,
#     который тикает каждую минуту и делит data/chat_last_id.txt);
#   * при ненулевом коде возврата уходит уведомление ADMIN_USER_ID —
#     иначе упавший аудит виден только тем, что отчёт не пришёл.
